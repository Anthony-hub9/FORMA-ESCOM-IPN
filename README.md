# FORMA-ESCOM-IPN (TT 2027-A045)

Sistema de gestión académica y capacitación extracurricular para la Escuela Superior de Cómputo (ESCOM - IPN).

## Estructura del Proyecto
- `backend/` — API REST y lógica de negocio en CodeIgniter 4 (PHP 8.3+) + Shield Auth
- `frontend/` — Capa de presentación responsiva (identidad IPN/ESCOM `#6C1D45`)
- `rag-service/` — Servicio de agente RAG (Python / FastAPI)
- `docker/` — Configuración de contenedores (Nginx, PHP-FPM, MariaDB)
